# Swan Wholesale Hub

Self-hosted wholesale portal for Swan Apothecary retail partners.

Stack:
- TanStack Start / React / TypeScript
- Nitro Node server
- Tailwind CSS
- Self-hosted Supabase
- PostgreSQL / Auth / PostgREST / Realtime / Storage
- Rootless Docker on the Studio387 server

Development:
- Copy .env.example to .env.
- Run bun install.
- Run bun run dev.

Production is built and deployed by the Studio387 platform. Lovable is not required to build or run this project.
